Strategia: anna Octaven tehdä työ
Sinun tehtäväsi on kirjoittaa oikea komento

Älä laske käsin jos Octave osaa. Kirjoita koodi → aja → kopioi vastaus. Suurin osa tenttipisteistä tulee oikeasta koodista, ei laskuvirheettömästä paperilaskusta.

Ennen Octavea

Yhtälöt tekstistä — ongelmanratkaisun logiikka

Tämä on se vaihe jonka kaikki unohtavat opettaa. Ennen kuin kirjoitat yhtään koodia, sinun täytyy muuttaa tekstitehtävä matematiikaksi. Tässä se resepti.

🗺️
Kuusivaiheinen resepti — aina sama järjestys
Kun seuraat tätä, mikä tahansa tekstitehtävä ratkeaa
  • 1
    Lue tehtävä kahdesti. Ensimmäisellä kerralla hahmota kokonaisuus. Toisella kerralla alleviivaa luvut ja nimeä mikä on mitäkin.
  • 2
    Listaa mitä tiedetään. Kirjoita paperille: "annettu: a = 5, b = 3, kulma = 40°". Älä luota muistiin.
  • 3
    Päätä mitä haetaan. Anna tuntemattomalle nimi: "haetaan: korkeus H" tai "haetaan: aika t". Tämä tulee Octavessa syms H:ksi.
  • 4
    Piirrä kuva. Geometriassa ja trigonometriassa AINA. Merkitse tunnetut arvot kuvaan. Kuvasta näkee yleensä minkä kolmion sisällä ollaan.
  • 5
    Kirjoita yhteys sanoin, sitten kaavaksi. "Korkeus jaettuna etäisyydellä on tangentti kulmasta" → H/x = tan(α). Tämä on se yhtälö jonka solve ratkaisee.
  • 6
    Ratkaise Octavella ja tarkista. Onko vastaus järkevä? Ei voi olla negatiivinen etäisyys. Sijoita takaisin yhtälöön.

Esimerkki 1: Nopeustehtävä
perusalgebra.m · s.47 — "Kahden vaiheen nopeus"

Tehtävä tekstinä: "Auto kiihdyttää ensin tasolla a₁ ajan t₁, sitten tasolla a₂ loppuajan (t₂ − t₁). Lopullinen nopeus on v. Laske t₁."

VaiheAjatusPaperilla
TiedetäänMolemmat kiihtyvyydet ja kokonaisaikaa₁, a₂, t₂, v annettu
HaetaanMilloin vaihdetaan tasoat₁ = ?
YhteysNopeus = kiihtyvyys × aika, kertynyt molemmista vaiheistav = a₁·t₁ + a₂·(t₂ − t₁)
OctaveRatkaistaan t₁solve(v == a1*t1 + a2*(t2-t1), t1)
octave >>perusalgebra.m · s.47
clear
syms v a1 a2 t1 t2
% Yhtälö suoraan sanallisesta kuvauksesta:
% "lopullinen nopeus = kiihd1 × aika1 + kiihd2 × (kokonaisaika - aika1)"
t1 = solve(v == a1*t1 + a2*(t2-t1), t1)
% → t1 = (v - a2*t2)/(a1 - a2)

% Tarkistus numeroin:
v=8.3; a1=0.4; a2=6.2; t2=9.8;
t1 = (a2*t2-v)/(a2-a1)
a1*t1 + a2*(t2-t1)   % → 8.3  ✓ sama kuin v

Esimerkki 2: Sekoitustehtävä
perusalgebra.m · s.69 — "Metalliseos"

Tehtävä tekstinä: "Sekoitetaan kolmea metallia: kultaa (1.00 €/g), hopeaa (1.26 €/g) ja pronssia (0.79 €/g). Halutaan 200 g seosta jonka hinta on 201 €. Kullan ja hopean suhde on 1:1.11. Kuinka paljon kutakin?"

VaiheAjatusPaperilla
TiedetäänKolmen metallin hinnat, kokonaispaino ja -hintarv=1.00, rg=1.26, re=0.79, V=200, M=201
HaetaanKullan (x) ja hopean (y) määrä, pronssI on loppux = ?, y = ?
Yhteys 1Kultaa ja hopeaa yhteensä: hinta per gramma = 1.11rv·x + rg·y = 1.11·(x+y)
Yhteys 2Kokonaishinta: kulta + hopea + pronssi = 201rv·x + rg·y + re·(200−x−y) = 201
OctaveKaksi tuntematonta, kaksi yhtälöäsolve(yht1, yht2, x, y)
octave >>perusalgebra.m · s.69
clear; syms x y
rv=1.00; rg=1.26; re=0.79; rvg=1.11; V=200; M=201;

% Yhtälö 1: kullan+hopean hintasuhde
yht1 = rv*x + rg*y == rvg*(x+y);

% Yhtälö 2: kokonaishinta
yht2 = rv*x + rg*y + re*(V-x-y) == M;

[x, y] = solve(yht1, yht2, x, y)
x = double(x)   % kultaa (g)
y = double(y)   % hopeaa (g)
V-x-y         % pronssia (g)

Esimerkki 3: Geometrinen korkeus
trigonometria.m · s.39-40 — "Korkeus kahdesta pisteestä"

Tehtävä tekstinä: "Tornin juurelta mitattu kulma on β = 20°. L = 3 metriä kauempaa mitattu kulma on α + β = 50°. Laske tornin korkeus h."

Piirretään kuva: Torni on pystysuora. Pisteestä A katsotaan kulmassa β, pisteestä B (joka on L metriä lähempänä) katsotaan jyrkemmässä kulmassa.

VaiheAjatusPaperilla
PiirräKaksi suorakulmaista kolmiota vierekkäin, yhteinen korkeus h✏️ kuvio paperille
Kolmio 1Lähempi piste B: tan(β) = h/xh = x · tan(β)
Kolmio 2Kaukaisempi piste A: tan(α) = h/(x+L)h = (x+L) · tan(α)
RatkaisuKaksi yhtälöä, kaksi tuntematonta: h ja xsolve(..., H, x)
octave >>trigonometria.m · s.39-40 & s.51-52
clear
h=3; alfa=30; beta=20;

% Kolmiosta 1: tan(beta) = h/x → x = h/tan(beta)
x = h*tand(beta)

% Kolmiosta 2: pituus L
L = h*tand(alfa+beta) - x

%% Yleinen ratkaisu: kun h on tuntematon
syms H x L a b
[H, x] = solve(H/x == tand(b), H/(L+x) == tand(a), H, x)
% H = L·tan(a)·tan(b) / (tan(b) - tan(a))

Esimerkki 4: Työtahtitehtävä
perusalgebra.m · s.49 — "Kaksi konetta yhdessä"

Tehtävä tekstinä: "Kone A tekee työn yksin 80 tunnissa. Yhdessä koneet tekevät sen 48 tunnissa. Kuinka kauan kone B tekee sen yksin?"

VaiheAjatusPaperilla
AvainajatusTunnissa tehty osuus on 1/aika. Osuudet lasketaan yhteen.—
YhtälöA:n osuus + B:n osuus = yhdessä tehty osuus1/tA + 1/tB = 1/tAB
HaetaantB kun tA=80 ja tAB=48tB = ?
octave >>perusalgebra.m · s.49
clear
syms tA tB tAB
% Yhtälö: 1/tA + 1/tB = 1/tAB
tB = solve(1/tA + 1/tB == 1/tAB, tB)
tB = simplify(tB)
% → tB = tA*tAB / (tA - tAB)

% Numeroin:
tA=80; tAB=48;
tB = tA*tAB/(tA-tAB)   % → 120 tuntia

% Tarkistus:
1/tA + 1/tB    % → 0.0208...
1/tAB          % → 0.0208...  ✓ sama!
💡
Työtahtitehtävän kaava: 1/yhdessä = 1/A + 1/B. Tämä pätee pumppuihin, putkiin, koneisiin, työtekijöihin — aina kun nopeudet (ei ajat) laskettaan yhteen.

Mallinnusharjoitukset — muodosta yhtälö ensin
Kirjoita yhtälö paperille ENNEN kuin avaat Octaven
Harjoitus M1
Muodosta yhtälö ja ratkaise
Pumppu A tyhjentää altaan 6 tunnissa. Pumppu B tekee sen 10 tunnissa. Kuinka kauan kestää yhdessä?
% Ajatus: tunnissa tehty osuus lasketaan yhteen
% 1/A + 1/B = 1/yhdessä
% 1/6 + 1/10 = 1/t_yhdessä
clear; syms t
t = solve(1/6 + 1/10 == 1/t, t)
t = double(t)   % → 3.75 tuntia

% Tarkistus:
1/6 + 1/10   % → 0.2667
1/3.75       % → 0.2667  ✓
✅ Yhdessä: 3 h 45 min. Yhtälö: 1/6 + 1/10 = 1/t
Harjoitus M2
Muodosta yhtälö ja ratkaise
Auto ajaa 80 km matkan. Ensin 40 km nopeus 60 km/h, sitten 40 km nopeus 120 km/h. Mikä on keskinopeus?
% Ajatus: keskinopeus = kokonaismatka / kokonaisaika
% Aika 1: 40/60 = 0.667 h
% Aika 2: 40/120 = 0.333 h
clear
s1=40; v1=60;
s2=40; v2=120;
t1 = s1/v1
t2 = s2/v2
kokonaismatka = s1 + s2
kokonaisaika  = t1 + t2
keskinopeus   = kokonaismatka / kokonaisaika
% → 80 km/h  (harmoninen, ei aritmeettinen!)
✅ Keskinopeus = 80 km/h. Ei ole (60+120)/2 = 90!
Harjoitus M3
Muodosta geometrinen yhtälö
Tikkaat nojaa seinään. Tikkaat ovat 5 m pitkät ja niiden alapää on 2 m seinästä. Kuinka korkealle ylettyy?
% Piirrä: suorakulmainen kolmio
% hypotenuusa = tikkaat = 5
% viereinen  = etäisyys seinästä = 2
% vastakkainen = korkeus = ?
%
% Pythagoras: h² + 2² = 5²  →  h = sqrt(25-4)
clear
tikkaat = 5;
etaisyys = 2;
korkeus = sqrt(tikkaat^2 - etaisyys^2)
% → 4.583 m

% Myös kulma maahan:
kulma = acosd(etaisyys/tikkaat)
% → 66.4°
✅ Korkeus ≈ 4.58 m. Yhtälö: h = √(5²−2²)

Muodosta yhtälö kirjainkaavaksi
Akku: jännite E, sisäinen resistanssi r, ulkoinen R. Virta i = E/(R+r). Ratkaise r kun E=12 V, R=10 Ω, i=1.1 A.
% Yhtälö suoraan tekstistä: i = E/(R+r)
% Haetaan: r
clear; syms r
E=12; R=10; i=1.1;
r = solve(i == E/(R+r), r)
r = double(r)   % → 0.909 Ω

% Tarkistus:

Symbolinen laskenta (syms)
Laskeminen kirjaimilla — Octaven supervoima

Normaalisti Octave laskee vain numeroilla. syms-komennon jälkeen se osaa laskea myös kirjaimilla, kuten paperilla.

octave >>
% Ilmoita kirjainmuuttujat
syms x y

% Nyt voi laskea kirjaimilla
expand((x+2)*(x+3))     % → x^2 + 5*x + 6
simplify((x^2-4)/(x-2)) % → x + 2

% Yhtälön ratkaisu
solve(x + 5 == 12, x)    % → x = 7
solve(x^2 == 9, x)       % → [3, -3]

% VAIHE: syms → komento → vastaus. Aina näin!
💡
Muistisääntö: syms x on kuin "esittely" — kerrot Octavelle kuka x on, ennen kuin pyydät sitä ratkaisemaan tehtävää jossa x esiintyy.

Octave-taito 1

Vektorit — Octaven lista-ajattelu

Tämä on se juttu joka erottaa Octaven tavallisesta laskimesta. Tavallinen laskin laskee yhden luvun kerrallaan. Octave laskee sata lukua yhtä aikaa — etkä kirjoita silmukkaa, vain yhden rivin.

📋
Arvolista: alku : askel : loppu
Kuin rullamitta — merkitse alku, loppu ja kuinka tiheästi

Ajattele tätä kuin rullamittaa: sanot mistä mitataan, mihin asti, ja kuinka tiheästi välimerkit ovat. Kurssimateriaaleissa tätä käytettiin joka sivulla — perusalgebra.m ja trigonometria.m ovat täynnä tätä rakennetta.

Syntaksi
muuttuja = alku : askel : loppu
Esim: h = 0 : 0.5 : 3 → [0, 0.5, 1.0, 1.5, 2.0, 2.5, 3.0]
octave >>trigonometria.m · s.17 & s.21
% Ajattele: "anna minulle luvut 1, 2, 3, 4, 5"
x = 1:5            % → [1, 2, 3, 4, 5]  (askel on 1 oletuksena)

% "Anna luvut 0, 0.5, 1.0, 1.5, 2.0"
x = 0:0.5:2        % → viisi lukua

% "Anna 100 lukua väliltä 0...10 tasaisin välein"
x = 0:10/100:10   % askel = 0.1

% Kurssista (trigonometria.m rivi 86): korkeus 0...DC
DC = sqrt(5^2 - (6/2)^2)   % ensin lasketaan DC
h = 0 : DC/10 : DC           % sitten lista 0...DC kymmenessä askeleessa

% Kurssista (trigonometria.m rivi 153): kulmat 0...360
alfa = 0:0.1:360

% Tarkka optimointi: pieni askel = tarkempi tulos
x = 0.01:0.001:20   % 20 000 pistettä — Octave ei väsy
🔸
Pistematematiikka: piste ennen operaattoria
Kun muuttuja on lista, lisää piste: .^ .* ./

Tässä kompastuvat kaikki ensimmäisellä kerralla. Kun Octavessa on lista lukuja, tavallinen ^ ei toimi odotetusti — se yrittää tehdä matriisimatematiikkaa. Piste ennen operaattoria tarkoittaa: "tee tämä jokaiselle luvulle listassa erikseen".

Helppo muistisääntö: näetkö koodissa listan (alku:askel:loppu)? Jos näet, käytä pistettä. Jos muuttuja on yksi luku, piste ei haittaa mutta ei ole pakollinen.

octave >>trigonometria.m · s.19
% Yksi luku → tavallinen ^ toimii
a = 3
b = a^2         % → 9  ✓

% Lista → PITÄÄ käyttää .^ (piste-hattu)
h = 0:0.5:3     % tämä on lista: [0, 0.5, 1.0, 1.5, 2.0, 2.5, 3.0]
tulos = h.^2    % → [0, 0.25, 1.0, 2.25, 4.0, 6.25, 9.0]  ✓
% tulos = h^2   ← tämä antaisi virheen tai väärän luvun!

%% Kurssista: trigonometria.m rivit 128-131 (s.19)
R = 1
r = 0:R/1000:R;            % lista (1001 arvoa)
H = 2*sqrt(R^2 - r.^2);   % .^2 koska r on lista
Vlierio = pi*r.^2.*H;       % .^2 JA .* koska molemmat listoja

% Operaattorit listalle:
%   .^  potenssi   (r.^2  = jokainen r korotettuna 2:een)
%   .*  kertolasku (a.*b  = parilliset alkiot kerrotaan)
%   ./  jakolasku  (a./b  = parilliset alkiot jaetaan)
⚠️
Varoitus: Octave ei aina sano virhettä kun unohdat pisteen — se vain antaa väärän vastauksen hiljaa. Jos kuvaajasi näyttää oudolta, tarkista ensin kaikki ^ ja * muuttujan jälkeen.

Min ja max — pienin/suurin arvo ja sen sijainti
Optimoinnissa käytetty kaikkialla kurssimateriaalissa

Ajattele näin: laskit lämpötilan joka tunnille koko päiväksi — sait listan 24 lukua. Haluat tietää millä tunnilla oli kuuminta, ja mikä se lämpötila oli. max() antaa molemmat: suurimman luvun ja sen järjestysnumeron listassa. Kurssissa tätä käytettiin löytämään optimikulma tai -korkeus.

octave >>trigonometria.m · s.17 & s.23
% [arvo, indeksi] = min(lista)
% indeksi kertoo MISSÄ KOHDASSA listaa minimi on

clear
a=5; b=6;
DC = sqrt(a^2-(b/2)^2);
h = 0:DC/100:DC;           % lista h-arvoista

MA = sqrt((b/2).^2 + h.^2);
MB = MA;
MC = DC - h;
s  = MA + MB + MC;           % summa jokaiselle h:n arvolle

[smin, indmin] = min(s)      % pienin arvo ja sen indeksi
hmin = h(indmin)             % h:n arvo siinä kohdassa

% Max toimii samoin
alfa = 0:0.01:360;
V = 1/3.*pi.*(alfa./360).^2.*sqrt(1-(alfa./360).^2);
[Vmax, indmax] = max(V)
alfamax = alfa(indmax)
💡
Ajattelutapa: Lista on kuin taulukko. min(s) etsii pienimmän luvun. indmin on sen rivinumero. h(indmin) on sama rivinumero h-taulukosta — eli se h:n arvo jolla s on pienin.

Plottaus — kuvaajien piirtäminen

Ajattele pisteistä yhdistettyä pisteiden piirtämistä. Teet listan x-arvoista ja listan y-arvoista, annat ne Octavelle, ja se piirtää kuvaajan automaattisesti. Kaikki kurssimateriaalin kuvaajat tehtiin näillä komennoilla.

While-looppi — numeerinen ratkaisu kun solve ei toimi
Kurssimateriaalissa käytetty kun symbolinen ratkaisu on mahdoton

Ajattele ämpäriä jonka täytät vesihanan alla. Lisäät vettä hiukan kerrallaan ja tarkistat onko se täynnä. while-looppi tekee saman asian: lisää pienen askelen, laske tulos, tarkista onko se tarpeeksi suuri — ja toista kunnes on. Kurssissa tarvittiin kun solve ei osannut ratkaista yhtälöä symbolisesti.

octave >>trigonometria.m · s.63-64
%% Halutaan: Vneste = 30, mikä h tarvitaan?
%% (solve ei osaa — käytetään while-looppia)
clear
r=2; R=3; H=4; V=30;

h      = 0;       % aloitetaan nollasta
dh     = 0.00001; % askeleen koko (pienempi = tarkempi)
Vneste = 0;       % alustetaan

while Vneste < V                   % jatka kunnes ylitetty
    h      = h + dh;
    x      = h/H*(R-r);
    s      = r + x;
    Vneste = 1/3*pi*(s^2+s*r+r^2)*h;
end

h       % ← tulos: h jolla Vneste ≈ 30
Vneste  % ← tarkistus: pitää olla lähellä 30
octave >>trigonometria.m · s.77-78
%% Vsuhde = 0.30 → mikä h?
clear
r=1; s=0.3;
h=0; dh=0.00001; Vsuhde=0;

while Vsuhde < s
    h      = h + dh;
    alfa   = 2*acos((r-h)/r);
    Vsuhde = 1/(2*pi)*(alfa-sin(alfa));
end
h
Vsuhde
💡
While-looppi mallina: (1) Alusta muuttujat nollaan. (2) Kirjoita while tulos < haluttu. (3) Lisää askelta: muuttuja = muuttuja + dh. (4) Laske uusi tulos. (5) end. Pienennä dh jos haluat tarkemman tuloksen.

➕
syms ... positive — rajoita muuttujien arvoja
Kerro Octavelle että muuttuja on positiivinen

Kun ratkaiset geometrisia suureita (pituus, säde, korkeus), ne ovat aina positiivisia. Lisäämällä positive Octave ei anna negatiivisia ratkaisuja ja lausekkeet yksinkertaistuvat.

octave >>
% Ilman positive: voi antaa ±-ratkaisuja
syms R h L
solve((R+h)^2 == R^2+L^2, L)
% → [-h^(1/2)*(2*R+h)^(1/2),  h^(1/2)*(2*R+h)^(1/2)]

% Positive: antaa vain järkevän vastauksen
syms R h L positive
solve((R+h)^2 == R^2+L^2, L)
% → h^(1/2)*(2*R+h)^(1/2)   ← siisti! ✓

Täydellinen esimerkkikaava kurssilta — kaikkea yhdessä
s. 21–24: kartiovaipan optimikulma

Tämä on kurssimateriaalin ehkä hienoin esimerkki — kaikki tekniikat käytössä samaan aikaan.

octave >>trigonometria.m · s.23-24
%% Missä kulmassa kartion tilavuus on suurin?
clear

alfa = 0:0.01:360;          % ① lista kulmista
r = alfa ./ 360;             % ② pistelaskenta: r jokaiselle alfalle
h = sqrt(1 - (alfa./360).^2); % ② .^2 koska lista
V = 1/3 .* pi .* r.^2 .* h;  % ② tilavuus jokaiselle

[Vmax, indmax] = max(V);     % ③ suurin ja sen indeksi
alfamax = alfa(indmax);       % ③ sitä vastaava kulma

plot(alfa, V, 'linewidth', 1.5)  % ④ piirrä
hold on
plot(alfamax, Vmax, 'r.', 'markersize', 25)
hold off
grid
xlim([0, 360]); xticks(0:30:360);
xlabel('\alpha'); ylabel('V', 'rotation', 0)

rmax = alfamax/360           % optimisäde
hmax = sqrt(1-(alfamax/360)^2)  % optimikorkeus
🎓
Rakenne tiivistetysti: ① Tee lista → ② Laske joka pisteessä (.^ .*) → ③ Etsi optimi (min/max) → ④ Piirrä ja merkitse. Tämä toistuu kurssin joka optimointitehtävässä.

Harjoittele ennen kuin kohtaat tehtävän tentissä
Harjoitus K1
Millä h:n arvolla h³ ylittää 100?
Käytä while-looppia, askel dh = 0.001
clear
h  = 0;
dh = 0.001;
while h^3 < 100
    h = h + dh;
end
h           % → ≈ 4.642
h^3         % tarkistus → ≈ 100 ✓
✅ h ≈ 4.642 (= ∛100)
Harjoitus K2
Sylinterisäiliö: millä korkeudella tilavuus on 30 yksikköä?
Säde r = 2, laske h kun V = π·r²·h = 30
clear
r=2; V_tavoite=30;
h=0; dh=0.0001; V=0;
while V < V_tavoite
    h = h + dh;
    V = pi * r^2 * h;
end
h        % → ≈ 2.387
V        % tarkistus → ≈ 30 ✓
% Tarkista myös: pi*r^2*h = 30 → h = 30/(pi*4)
✅ h ≈ 2.387. Tarkistus: π·4·2.387 ≈ 30 ✓
Harjoitus K3
Muunna symbolinen vastaus numeroksi
Ratkaise 3x² − 12 = 0 symbolisesti, sitten double()
clear; syms x

Aputaulukot

Muunnostaulukot ja vakioarvot

Nämä kannattaa pitää auki tenttiin. Radiaanit, tärkeimmät kulma-arvot ja Octaven vakiot.

🔄
Mitä radiaanit ovat?
Toinen tapa mitata kulmia — kuin km vs. maili

Asteet (°) ovat tuttu tapa: ympyrässä on 360°. Radiaanit ovat toinen yksikkö samalle asialle — ympyrässä on 2π radiaania (noin 6.28). Miksi radiaaneja on olemassa? Koska niillä monet matematiikan kaavat yksinkertaistuvat huomattavasti. Kurssimateriaaleissa näet molempia.

Käytännön sääntö Octavessa: käytä sind/cosd/tand → ei tarvitse koskaan muuntaa. Jos koodia on valmiina radiaaneilla, muunnoskaavat alla.

Muunnoskaavat
radiaanit = asteet × π / 180
asteet = radiaanit × 180 / π

Octavessa: rad = aste * pi/180  |  aste = rad * 180/pi

Perusalgebra

Lausekkeiden sieventäminen, yhtälöiden ratkaiseminen ja yhtälöryhmät. Kaikki ratkeavat Octavella.

🧩
Sulkujen avaaminen ja sieventäminen
expand() avaa, simplify() sieventää, factor() tekijöi

Ajattele lauseketta kuin origamia: expand levittää sen auki, simplify taittelee sen siistiksi. Sieventäminen tarkoittaa yksinkertaistamista — sama asia lyhyemmässä muodossa.

octave >>perusalgebra.m · s.9 & s.14
clear
syms x

expand((2*x+3)*(4-5*x))     % → -10x² - 7x + 12
simplify(2*x*y^2+4*x^2*y)  % → 2xy(y + 2x)
factor(9*x^4-4)              % → (3x²-2)(3x²+2)

% Murtolausekkeet
simplify(2*x*y/(x^2+x*y))   % → 2y/(x+y)
🔍
Yhtälön ratkaiseminen
solve(yhtälö, muuttuja) — kaksi yhtäsuuruusmerkkiä!

Yhtälö on kuin vaaka: vasemmalla ja oikealla puolella pitää olla sama paino. solve selvittää millä x:n arvolla vaaka on tasapainossa. Muista aina kaksi yhtäsuuruusmerkkiä yhtälössä.

Kaava
solve(vasen == oikea, x)

% Kirjaimilla: ratkaistaan r, kun E/e = (R+r)/r
syms E e R r
r = solve(E/e == (R+r)/r, r)      % → r = R*e/(E-e)

Osa 2

Trigonometria

Kolmiot, kulmat ja pituudet. Sinilause, kosinilause ja Octaven trig-funktiot.

📐
Perusfunktiot suorakulmaisessa kolmiossa
sin, cos, tan — selitys esimerkin kautta

Kuvittele nojatikkaat seinää vasten. Tikkaiden pituus on hypotenuusa. Seinän korkeus johon ne ylettyy on vastakkainen sivu. Lattialla oleva matka seinään on viereinen sivu. Kulma α on tikkaiden ja lattian välinen kulma.

sin kertoo: "kuinka suuri osa tikkaiden pituudesta on pystysuoraa?". cos kertoo: "kuinka suuri osa on vaakasuoraa?". tan kertoo: "kuinka paljon nousee yhdellä vaakametrillä?"

Kaavat — laita lapulle!
sin(α) = vastakkainen / hypotenuusa
cos(α) = viereinen / hypotenuusa
tan(α) = vastakkainen / viereinen

Muistisääntö: SOH-CAH-TOA (Sin=Opp/Hyp, Cos=Adj/Hyp, Tan=Opp/Adj)
octave >>trigonometria.m · s.29-30
% Aste-versiot — käytä AINA tentissä
sind(30)    % → 0.5
cosd(60)    % → 0.5
tand(45)    % → 1.0

% Käänteisfunktiot: selvitä kulma
asind(0.5)  % → 30°
acosd(0.5)  % → 60°
atand(1)    % → 45°

% Pythagoraan lause
a=3; b=4;
c = sqrt(a^2 + b^2)  % → 5
⚠️
Kriittinen ero: sin(30) = 0.988 (radiaanit!), sind(30) = 0.5 (asteet). Käytä d-versiota!
🔺
Kosinilause — kun kolmiossa ei ole suoraa kulmaa
Tunnet 2 sivua + kulman → laske 3. sivu. Tai kaikki sivut → laske kulmat.

Pythagoraan lause toimii vain suorakulmaisessa kolmiossa. Kosinilause toimii kaikilla kolmioilla. Jos kolmiossa on suora kulma, kosinilause antaa saman tuloksen kuin Pythagoraan lause — joten se on turvallinen valinta aina.

Kosinilause — laita lapulle!
c² = a² + b² − 2ab·cos(γ) ← kun tunnet 2 sivua ja niiden välisen kulman
cos(α) = (b²+c²−a²) / (2bc) ← kun tunnet kaikki 3 sivua, haluat kulman
octave >>trigonometria.m · s.101-104
clear
% Sivun laskeminen (tunnetaan a, b, gamma)
a=4.3; b=6.2; gamma=25;
c = sqrt(a^2 + b^2 - 2*a*b*cosd(gamma))

% Kulmien laskeminen (tunnetaan kaikki sivut)
clear
a=2.7; b=3.3; c=1.4;
alfa  = acosd((b^2+c^2-a^2)/(2*b*c))
beta  = acosd((a^2+c^2-b^2)/(2*a*c))
gamma = acosd((a^2+b^2-c^2)/(2*a*b))
alfa+beta+gamma   % ← pitää olla 180!
📏
Sinilause — sivut ja vastakkaiset kulmat
Tunnet yhden sivun ja kaksi kulmaa → saat kaikki sivut

Sinilauseessa joka sivu on suhteessa sitä vastapäätä olevaan kulmaan. Jos tiedät yhden sivun ja sen vastakkaisen kulman, voit laskea kaikki muut sivut — kunhan tiedät myös niiden vastakkaiset kulmat. Kolmion kulmien summa on aina 180°, joten kolmaskin kulma selviää helposti.

Sinilause
a/sin(α) = b/sin(β) = c/sin(γ)
→ b = sin(β) · a / sin(α)
octave >>trigonometria.m · s.111-112
clear
a=8.6; alfa=54; beta=97; gamma=29;

b = sind(beta)  * a / sind(alfa)
c = sind(gamma) * a / sind(alfa)

alfa+beta+gamma   % → 180 ✓

Pisteestä, korkeudesta, etäisyydestä

  • 2 Tunnista oikeat kolmiot kuviossa
  • 3 Ratkaise askel kerrallaan — jokainen uusi tieto auttaa seuraavaan
  • 4 Tarkasta: kulmien summa = 180, tai sijoita takaisin
